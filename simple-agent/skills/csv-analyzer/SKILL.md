# CSV 分析技能

## 何时使用
- 用户明确提到 CSV / 表格 / 数据集
- 需要计算总数、均值、最大最小、分位数
- 需要按某列分组聚合（groupby）
- 需要识别空值、重复行、异常离群点

## 推荐操作流程

### Step 1：探查数据结构
先让用户告诉你 CSV 路径，然后读取前若干行（例如用 `read_note` 读取预览）。识别列名、类型、是否含表头。

### Step 2：选择分析角度
- 数值列：均值、中位数、标准差、min/max、四分位数
- 类别列：唯一值数量、频次 Top 10、空值比例
- 时间列：最早/最晚、覆盖时间跨度

### Step 3：生成统计摘要
用自然语言汇总关键结论，给出 3~5 条最重要的洞察（不要把全表倒出来）。

## 输出规范
- **先结论、后数据**：前 3 句给核心发现，再附表格细节
- **异常必须高亮**：发现空值比例 > 10%、单类别占比 > 90% 等情况务必提示用户
- **必要时建议下一步**：例如"建议对 age 列做异常值剔除后再分析"

## 禁止事项
- 不要把超过 20 行的原始数据贴出来
- 不要擅自修改用户的数据文件
- 没有数据时不要瞎编数字
